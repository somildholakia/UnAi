# Security policy

unAI is an experimental agent. Do not expose it to untrusted users or public traffic until authentication, rate limits, tenant isolation, audit logging, sandbox hardening, and secret handling have been reviewed.

Report security issues privately to the repository owner. Do not include API keys, credentials, private source code, or personal data in public bug reports.

Current prototype limitations: no authentication, no multi-tenant boundary, no production sandbox image hardening, and no production deployment configuration. Run it on loopback only.
